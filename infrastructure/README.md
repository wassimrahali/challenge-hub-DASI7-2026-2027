# Infrastructure

Configuration de lancement local et de déploiement de ChallengeHub : bases de données (PostgreSQL, MySQL, MongoDB), Keycloak, Eureka, Config Server et API Gateway.

Les ports, variables d'environnement et l'ordre de démarrage sont décrits dans [configuration.md](../documentation/technical/configuration.md). Les fichiers de lancement (par exemple Docker Compose) seront ajoutés ici avec les premiers services.
